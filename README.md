# Space Dragon

A family of five explores the universe in a giant mecha dragon, returning home to a supportive Florida cul-de-sac and a fictional neighbor determined to get the dragon out of the street.

**Status:** concept and specification. This commit adds planning documents, not a playable game or a deployment.

**Planned game location:** `paulmalmquist.com/space-dragon`. The existing homepage must remain intact. This is a target route, not a claim that the game is live.

## The experience

Fly the dragon, make light-speed jumps, explore new destinations, make discoveries, and return home with an upgrade. Florida-themed antagonists include iguanas and alligators, with other enemy ideas reserved for later missions.

The bookmarked **Line Leader** system allows the family to leave the dragon together or in smaller groups. The player controls one person at a time; everyone else in that party follows automatically. This is a future single-player party mechanic, not an approved multiplayer feature.

## Proposed delivery sequence

1. Audit the existing website and deployment, and prototype dragon flight on a chosen device.
2. Build the small **Launch Day** expedition described in the specification.
3. Add one walkable location, leader switching, automatic followers, and contextual suit assists.
4. Add split-party exploration, regrouping, and additional missions.

This sequence is a proposed plan. Uploading the documents does not approve all future scope or start deployment.
