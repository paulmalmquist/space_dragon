# Script — A1-05 Install Parties and the Neighbor's Escalation (by install count)

**Status:** PROPOSED draft. Shared by every Act I mission script.  
**Why it's keyed by count:** missions 2–5 can be played in any order, and mission 6 (Propulsion) unlocks only after all four. Story beats that must stay in order come from **how many** modules are installed, not **which** one ([Act I refinements](../ACT_I_CRITIQUE_AND_REFINEMENTS.md) §4.1). Each mission script adds only its **module demo** and **home change**.

## Order of every install party

1. **The reunion.** The module and the Core reach for each other. The living material knits together, and the Builder Bugs (once unlocked) do the docking dance.
2. **The module demo.** Specific to the module, from the mission script.
3. **The SOS.** It plays with this count's layer and note.
4. **The Core speaks.** This count's vocabulary.
5. **The baking neighbor.** This count's treat.
6. **A hearth moment.** A short, warm family beat.
7. **[SAVE]**
8. **The neighbor's escalation.** It happens *between* missions: overnight, or the next morning at the planning station.

All of it is **[CINE]**, skippable once seen. A skip applies the same state. Replays from the archive grant nothing.

## Things that change only with a specific module

These are module-specific and order-independent. Each mission script includes its own.

| Module | Permanent home change |
| --- | --- |
| Assembly (preschool) | Builder Bugs |
| Navigation (Luke's school) | The planning station becomes a **star map**, and the **fading star** appears |
| Power (warehouse) | The Core **glows at night**, and the street notices |
| Life Support (grocery) | **The passenger** lives at the house and hums the SOS |
| Wing Control (big-box) | The dragon hologram's wings **flex**, and the neighbor sees it |
| Propulsion (rocket facility) | The dragon's **body stands complete**, then it doesn't wake |

## Conditional lines

- **If the passenger is home** (Life Support installed): at each later party it hums along with the SOS, one beat behind, and the Core chimes at it fondly.
- **If the fading star is visible** (Navigation installed): at each later party, Lyla glances up and her visor shows it a little dimmer. The Core chirps at it. **It never closes in Act I.**
- **Luke's running promise** (from mission 1, "Next time I climb"): if Luke's school is still unplayed, Luke says at a party, "Still haven't climbed anything." Once it's played, the line is retired.

## Hearth moments (pick one per party, without repeats)

- The kids teach the Core a word. It's optional practice, never a gate, and it counts as practice, not mastery.
- Paul and Maria on the back step after bedtime, looking at the hologram. MARIA: "Somebody out there needs this." PAUL: "Yeah."
- Builder Bugs reenact the mission with tiny props, and Lyla records it.
- The family eats the baker's treat on the blanket next to the Core.
- Lyla shows her archive cards to the Core. It chimes at each one.
- Luna shows the Core how she slides, and the Core tries to slide too. It can't.
