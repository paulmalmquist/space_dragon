# Your idea inbox

Put any thought in [INBOX.md](INBOX.md), use the local prototype's idea notebook, or just tell the agent in chat. A sentence, a rough scene, a reference link, a correction, or a list in any order is enough. You do not need to choose a folder, assign a priority, or explain how to build it.

Examples:

> The dragon should feel really heavy when it lands.
>
> I changed my mind about the backyard scene—show the signal from inside first.
>
> Save this for later: Luna makes an alligator slide into a shopping cart.

Agents preserve your words, connect them to the right story/art/game work, and keep [the idea ledger](../docs/project/IDEA_LEDGER.md) and [current status](../docs/project/STATUS.md) updated. The local notebook appends a `NOTE-...` capture to the inbox; an agent assigns an `SD-###` tracking ID when processing it. You can change your mind; the agent records what the new idea replaces.

Only add a link or timestamp when it helps explain what you like about a reference. New private family footage can stay outside the repository; describe where it lives without committing it. Existing reference photos are already organized separately.

To ask an agent to catch up, say: **“Process my new ideas and continue the next useful step.”** Agents run when you invoke them; saving a file alone does not launch a background agent.
